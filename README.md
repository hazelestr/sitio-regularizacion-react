# Sitio Web Educativo de Regularización Escolar

Prototipo académico del Proyecto II (Licenciatura en Desarrollo de Sistemas Web, CUCEI, Universidad de Guadalajara, 2026). Sitio para reforzar matemáticas, español y ciencias.

## Estado actual: Sprint 4 (cierre del 11 de noviembre de 2026)

- HU-05 Panel de avance, HU-06 Foro de dudas y HU-07 Plan personalizado ahora guardan sus datos en una base de datos compartida (Firebase Firestore) con actualización en tiempo real.
- Cuentas con contraseña y roles: alumno, familia, docente y administrador.
- Videos (enlazados de YouTube), resúmenes, ejercicios, examen diagnóstico, guías en PDF, foro con moderación y notificaciones.

## Historial por sprint
- Sprint 1 a 3: funciones base, cuentas, roles, guías descargables y videos.
- Sprint 4: base de datos compartida con Firebase.

## Pendientes
- Configurar las reglas de seguridad de Firestore.
- Probar el sitio en una tablet real.
- Dividir los datos en colecciones por usuario.

## Tecnologías
React, TypeScript, Vite y Firebase Firestore.
